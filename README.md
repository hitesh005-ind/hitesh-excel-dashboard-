# 📊 Student Digital Wellbeing Dashboard

A data analytics project built around student digital habits, sleep patterns, stress levels, mental wellbeing, and academic performance using Excel.

## 📌 Project Overview

This project explores a dataset of **4,500 student records** and presents its information in a structured, easy-to-understand dashboard.

The aim is to turn raw student data into meaningful summaries using Excel charts, KPI cards, and analysis tables.

## 🎯 Project Objectives

* Analyze students' daily digital-platform usage.
* Compare usage across different platforms.
* Explore sleep duration and sleep quality.
* Examine perceived stress scores.
* Summarize mental-health index values.
* Review academic performance using GPA.
* Present key information in a professional dashboard.

## 📂 Dataset Information

The dataset contains 4,500 student records with 16 columns.

| Column Name                   | Description                      |
| ----------------------------- | -------------------------------- |
| `Student_ID`                  | Unique student record identifier |
| `Age`                         | Student's age                    |
| `Gender`                      | Gender category                  |
| `Academic_Level`              | Academic level                   |
| `Primary_Platform`            | Main digital platform used       |
| `Daily_Usage_Hours`           | Daily usage in hours             |
| `Weekend_Extra_Hours`         | Additional weekend usage         |
| `Device_Type`                 | Device category                  |
| `Sleep_Duration_Hours`        | Hours of sleep                   |
| `Sleep_Quality_Score`         | Sleep-quality score              |
| `Late_Night_Usage`            | Late-night usage category        |
| `Social_Comparison_Frequency` | Frequency of social comparison   |
| `Perceived_Stress_Score`      | Perceived stress score           |
| `Mental_Health_Index`         | Mental-health index              |
| `Academic_Performance_GPA`    | Academic GPA                     |
| `Overall_Impact`              | Overall impact category          |

## 📈 Dashboard Features

### 1. KPI Cards

* Total Students
* Average Daily Usage
* Average Sleep Duration
* Average Perceived Stress
* Average GPA

### 2. Charts

* **Platform Usage:** Compare average daily usage by primary platform.
* **Overall Impact:** Visualize the distribution of impact categories.
* **Stress Analysis:** Explore the distribution of perceived stress scores.
* **Academic Level:** Compare the number of students across academic levels.

### 3. Analysis Sheet

Contains summary tables that support the dashboard charts and comparisons.

### 4. Student Data Sheet

Contains the detailed student dataset in a filterable, organized table.

## 🛠️ Tools & Technologies

* Microsoft Excel

## 🔍 Questions This Project Explores

1. Which platforms have the highest average daily usage?
2. How much sleep do students report on average?
3. What patterns appear in perceived stress scores?
4. How are students distributed across overall-impact categories?
5. How does academic performance vary across student groups?

## 🚀 How to Use the Project

1. Open the Excel workbook.
2. Visit the **Dashboard** sheet for the overall summary.
3. Explore the **Analysis** sheet for supporting tables.
4. Open the **Student Data** sheet to filter or sort records.
5. Use the charts to explore patterns in the dataset.
